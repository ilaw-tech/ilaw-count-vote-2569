# iLaw Count Vote 2569

เครื่องมือเว็บแบบ self-contained สำหรับช่วยนับและตรวจสอบคะแนนเสียงในกระบวนการเลือกตั้ง โดย iLaw

A self-contained web tool for counting and verifying votes, built by iLaw.

## Live site

After enabling GitHub Pages, the app will be available at:

`https://<your-username>.github.io/ilaw-count-vote-2569/`

## How to run locally

The app is a single HTML file with React + Babel loaded from CDN. No build step.

- Double-click `index.html`, or
- Serve the folder with any static server, e.g. `python -m http.server`

## Tech

- React 18 (UMD build) + Babel Standalone — in-browser JSX
- Noto Sans Thai (Google Fonts)
- No bundler, no backend
